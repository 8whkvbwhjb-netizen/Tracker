# Lantern Keep

An original maze game in the style of an early-1980s Intellivision cartridge:
160 × 96 pixels, the 16-colour palette, eight moving objects, a keypad overlay
and three-voice square-wave sound.

**Play:** open `index.html` in a browser. There's nothing to install or build.

**Controls**

| Controller | Keyboard | Action |
|---|---|---|
| Disc | Arrow keys / WASD | Move |
| Side buttons | Space, Z, X | Shoot |
| Key 1 | 1 | Flare (freeze creatures) |
| Key 3 | 3 | Drop a bell (decoy) |
| Key 5 | 5, P, Esc | Pause |
| Key 7 | 7, M | Sound on/off |
| CLR | Backspace | Quit (while paused) |
| ENT | Enter | Start |

The on-screen controller works with touch, so it also plays on a phone.

See [DESIGN.md](DESIGN.md) for the full design: hardware constraints, maze
generation, creature AI, difficulty curve and future ideas.
